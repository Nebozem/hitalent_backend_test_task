# API организационной структуры

Тестовое задание: API для управления иерархической структурой подразделений и сотрудников.

## Технологии

- FastAPI
- SQLAlchemy 2.0 (Mapped аннотации)
- PostgreSQL
- Alembic (миграции)
- Docker / Docker Compose
- Pytest (9 тестов)

## Быстрый старт

```bash
docker-compose up --build
```

## Документация
```
После запуска: http://localhost:8000/docs
```

# Эндпоинты:

- POST	/departments	Создать новое подразделение
- POST	/departments/{id}/employees	Добавить сотрудника в подразделение с указанным ID
- GET	/departments/{id}	Получить иерархическое дерево подразделений (начиная с указанного подразделения)
- PATCH	/departments/{id}	Переместить подразделение в другую часть иерархии
- DELETE	/departments/{id}?mode=cascade/reassign	Удалить подразделение с выбором режима: cascade (удалить вместе с дочерними элементами) или reassign (переназначить дочерние элементы)

# Запуск тестов

# Особенности реализации
Уникальность названий подразделений: в пределах одного родительского подразделения не может быть двух подразделений с одинаковыми названиями.

Защита от циклических связей: при перемещении подразделения система проверяет, не приведёт ли операция к образованию циклической ссылки в иерархии.

Два режима удаления:

cascade — полное удаление подразделения вместе со всеми дочерними подразделениями и сотрудниками;

reassign — удаление подразделения с переназначением его дочерних элементов к другому (указанному) родительскому подразделению.

Рекурсивное построение дерева: при запросе дерева подразделений система строит иерархию рекурсивно, с ограничением глубины в 5 уровней (для предотвращения избыточной нагрузки на БД и клиент).
