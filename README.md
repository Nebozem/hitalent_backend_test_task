# API организационной структуры

Тестовое задание: API для управления иерархической структурой подразделений и сотрудников.

## Технологии

- FastAPI
- SQLAlchemy 2.0 (Mapped аннотации)
- PostgreSQL
- Alembic (миграции)
- Docker / Docker Compose
- Pytest (9 тестов)

## Быстрый старт

```bash
docker-compose up --build
После запуска: http://localhost:8000/docs
